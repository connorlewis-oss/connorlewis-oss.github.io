# Step 1: Audit — understand before you clean import pandas as pd df = pd.read_csv('hospital_ops_raw.csv') # Shape check print(df.shape) # (12847, 18) print(df.dtypes) print(df.isnull().sum()) # 847 nulls in 'insurance_code', 357 in 'fte_actual' print(df.describe()) # Spot the outliers df[df['avg_los_days'] > 30].shape[0] # 42 rows — flag these df[df['fte_actual'] < 0].shape[0] # 12 rows — impossible, drop

What I found: 847 missing insurance codes (billing team hadn't reconciled), 357 nulls in FTE actual (weekend data gaps), 12 negative FTE rows (data entry errors). Before touching anything, I documented every issue in a data quality log so stakeholders know exactly what was cleaned and why.

02
Clean Methodically — Every Decision Documented
Cleaning without documentation is just guessing. Every imputation has a rationale.
DONE ✓
# Step 2: Clean with documented rationale # FTE nulls → forward-fill within unit (weekend carryover logic) df['fte_actual'] = df.groupby('unit')['fte_actual'].transform( lambda x: x.fillna(method='ffill').fillna(method='bfill') ) # Negative FTE → drop (12 rows, data entry confirmed by supervisor) df = df[df['fte_actual'] >= 0] # Insurance nulls → flag as 'PENDING' (not imputed — billing must reconcile) df['insurance_code'] = df['insurance_code'].fillna('PENDING') # LOS outliers > 30 days → separate long-stay cohort, don't drop df['long_stay_flag'] = df['avg_los_days'] > 30 print(f"Clean dataset: {df.shape[0]} rows, {df.isnull().sum().sum()} nulls") # Clean dataset: 12,835 rows, 0 nulls

Key decision: I don't impute insurance codes with a mean or median — that would be fabricating billing data. I flag them as PENDING and escalate to the billing team. This is the difference between a good analyst and a dangerous one: knowing when not to fill a gap.

03
Surface 3 Actionable Insights
Not observations — insights with a "so what" and a recommendation attached
DONE ✓

NICU FTE is overstaffed 18% on weekends vs weekday census demand. Weekend average census = 14.2 patients but staffing is set for 17. Recommendation: adjust weekend FTE targets by unit census forecast — estimated savings $42K/quarter at current RN hourly rates.
#2
Insurance PENDING backlog is concentrating in Observation unit (61% of all 847 flags). This is a revenue recognition risk — pending codes = unbooked reimbursement. 30-day reconciliation target would recover an estimated $184K in delayed revenue.
#3
Long-stay patients (LOS >30 days) represent 0.33% of cases but 11.2% of total bed-days. This cohort disproportionately strains Observation capacity. Flagging for case management review could free 3–4 beds/week for new admissions.
